### Какво да очакваме от C ?

C е език от ниско ниво, който е с големи възможности и ни позволява да създаваме всичко, което бихме искали.

**Програмен език от ниско ниво** - това е такъв програмен език, който има малка или съвсем липсва абстракция от архитектурата на набора на инструкции на компютъра. 

Защо използваме C ?

C е доста базов език, който ни дава възможност да създадем всичко, което бихме искали, но в замяна трябва да положим усилени часове труд в изучаването и разбирането му.

- С е удобен инструмент да научим как интерфейсът си взаимодейства с паметта на компютъра на ниско ниво както и защо работата с паметта е важна.
- C се използва за създаване на софтуерни системи 

Езикът C заражда идеи за създаването на много други полезни езици като Rust, Swift, Python, Java затова може да припознаете части от него в тези езици.

### Променливи и примитивни типове
Обикновено променливите се гледат като неща, които съдържат/притежават някакви стойности. Друг начин да мислим за променлива е като име, което отговаря/съответства на някакви данни в паметта.

Когато имаме променлива в С, нейната стойност се записва някъде в паметта на някакъв адрес. Но тъй като е неудобно постоянно да назоваваме стойността с нейния адрес ние ѝ даваме име, което лесно можем да запомним и да разберем контекста, в който я използваме.

Така променливата е просто име за някаква стойност от някакъв тип, която се записва на някакъв адрес някъде в паметта.

### Декларация на променлива:

- <тип> <име> = (<стойност>)  

### Наименуване на променлива
Можем да наименуваме променливата с цифри и букви от 0-9, A-Z, a-z както и долна черта, но трябва да се спазват следните правила:

* Променливата не може да започва с цифра от 0-9.
* Променливата не може да започва с две долни черти една след друга.
* Променливата не може да започва с долна черта, която е последвана от главна буква.

### Примитивни типовe:

- Целочислен тип (int, short, long ..)

- Числа с плаваща запетая (double, float ..)

- Символен тип (char)

Булев тип
В С не разполагаме с вграден булев тип, което изобщо не е проблем, ако се придържаме към логиката на булевия тип. Обикновено се използва 0, за да кажем “false” и някоя ненулева стойност, за да кажем “true”.

Можем да декларираме такава променлива просто с тип int.

### Първа програма на C 
```c
/*Hello World програма*/
#include <stdio.h>

int main() {

  printf("Hello World!\n");
  
  return 0;
}
```

### Полезни бележки преди да преминем напред
Преди да използваме някоя променлива в С, първо трябва да я декларираме и да кажем на С от какъв тип искаме съответната променлива да бъде. Веднъж щом променливата е декларирана, типът ѝ не може да бъде променян по време на работа с програмата.

```c
#include <stdio.h>

int main() {

int i;    //Декларираме променлива от тип цяло числови име i, съответно тя може да съдържа стойности от вида -1, -3547, 0, 7, 63820

float f; //Декларираме променлива от тип число с плаваща точка, съответно тя може да съдържа стойности от вида -3.60, -1.15, 345.5, 3000
}
```  
  
В момента декларирани така променливите все още не са използвани както и са неинициализирани.

Неинициализираните променливи имат неясни стойности за нас. Тоест нека вземем променливата i, която сме декларирали по-горе, тя е неинициализирана, тогава е вероятно, че тя съдържа някакво число, което не прави смисъл за нас като например 342517. Ако променливата е неинициализирана, приемаме, че тя има някаква безсмислена за нас стойност.

Хубаво е винаги да инициализираме променливите преди да ги използваме.  

```c
#include <stdio.h>

int main() {

int i = 2; //декларираме променлива от тип int с име i и я инициализираме със стойност 2.

}
```

Всеки оператор се характеризира с:

- Приоритет 

Приоритетът (precedence) определя кой оператор се изпълнява първи, когато в един израз има няколко оператора.

Пример:
```c
int x = 2 + 3 * 4;
```
Умножението * има по-висок приоритет от събирането +.

```c
Следователно първо:
3 * 4 = 12 и след това: 2 + 12 = 14
Резултатът е:
x = 14;
```
Ако искаме да променим реда, използваме скоби:
```c
int x = (2 + 3) * 4;
```

Тогава първо се изпълнява 2 + 3 и резултатът е 20.

- Асоциативност

Асоциативността определя в каква посока се групират операторите, когато те имат еднакъв приоритет.

Пример:
```c
int x = 20 / 5 * 2;
```
Операторите / и * имат еднакъв приоритет. Те са ляво-асоциативни.

Затова изразът се разбира като:
```c
(20 / 5) * 2
Резултатът е: 4 * 2 = 8
А не:
20 / (5 * 2)
```

- Позиция на оператора спрямо аргумента - префиксен, инфиксен и суфиксен (постфиксен)

ПРЕФИКСЕН ОПЕРАТОР

При префиксния оператор операторът се намира ПРЕДИ операнда.

Обща форма: ОПЕРАТОР x

Примери:
```c
++x
-x
!x
При: ++x операторът ++ е пред x, затова е префиксен.

При: -x минусът е пред x, затова е префиксен унарен оператор.
```

ИНФИКСЕН ОПЕРАТОР

При инфиксния оператор операторът се намира МЕЖДУ два операнда.

Обща форма: x ОПЕРАТОР y

Примери:
```c
a + b
a - b
a * b
a / b

При: a + b имаме:

a → операнд
+ → оператор
b → операнд

Затова + е инфиксен оператор.

Инфиксният оператор обикновено е бинарен, т.е. работи с два операнда.
```

ПОСТФИКСЕН (СУФИКСЕН) ОПЕРАТОР

При постфиксния оператор операторът се намира СЛЕД операнда.

Обща форма: x ОПЕРАТОР

Примери:
```c
x++
x--

При: x++ операторът ++ е след x, затова е постфиксен.
```

## Най-често използвани форматиращи спецификатори в C

| Спецификатор | Тип данни | Пример |
| :--- | :--- | :--- |
| `%d` | Integer (Цяло число) | `printf("%d", 42);` |
| `%u` | Unsigned int (Цяло число без знак/ положително число) | `printf("%u", 42);` |
| `%f` | Float (Число с плаваща запетая) | `printf("%f", 3.14);` |
| `%lf` | Double (Число с двойна прецизност) | `printf("%lf", 3.14);` |
| `%Lf` | Long double  | `printf("%Lf", 3.14L);` |
| `%s` | String (Текст / Низ) | `printf("%s", "Hello");` |
| `%c` | Character (Символ) | `printf("%c", 'A');` |
| `%p` | Pointer Address (Адрес на указател) | `printf("%p", ptr);` |
