Всеки оператор се характеризира с:

- Приоритет 

Приоритетът (precedence) определя кой оператор се изпълнява първи, когато в един израз има няколко оператора.

Пример:
```c
int x = 2 + 3 * 4;
```
Умножението * има по-висок приоритет от събирането +.

Следователно първо:
3 * 4 = 12

След това:
2 + 12 = 14

Резултатът е:
x = 14;

Ако искаме да променим реда, използваме скоби:

int x = (2 + 3) * 4;

Тогава първо се изпълнява 2 + 3 и резултатът е 20.

Накратко:
ПРИОРИТЕТЪТ ОПРЕДЕЛЯ КОЙ ОПЕРАТОР ИМА ПРЕДИМСТВО ПРЕД ДРУГ.


2. АСОЦИАТИВНОСТ

Асоциативността определя в каква посока се групират операторите, когато те имат еднакъв приоритет.

Пример:

int x = 20 / 5 * 2;

Операторите / и * имат еднакъв приоритет. Те са ляво-асоциативни.

Затова изразът се разбира като:

(20 / 5) * 2

Резултатът е:

4 * 2 = 8

А не:

20 / (5 * 2)

Друг пример:

int x = 10 - 3 - 2;

Операторът - е ляво-асоциативен.

Следователно:

(10 - 3) - 2 = 5

Накратко:
ПРИОРИТЕТЪТ КАЗВА КОЙ ОПЕРАТОР Е ПЪРВИ.
АСОЦИАТИВНОСТТА КАЗВА КАК СЕ ГРУПИРАТ ОПЕРАТОРИ С ЕДНАКЪВ ПРИОРИТЕТ.


3. ПОЗИЦИЯ НА ОПЕРАТОРА СПРЯМО ОПЕРАНДА

Според позицията си спрямо операнда операторите могат да бъдат:

- префиксни;
- инфиксни;
- постфиксни (суфиксни).

Важно:
ОПЕРАТОРЪТ е символът/конструкцията, която извършва операция.
ОПЕРАНДЪТ е стойността или изразът, върху който операторът действа.


3.1. ПРЕФИКСЕН ОПЕРАТОР

При префиксния оператор операторът се намира ПРЕДИ операнда.

Обща форма:

ОПЕРАТОР x

Примери:

++x
-x
!x

При:

++x

операторът ++ е пред x, затова е префиксен.

При:

-x

минусът е пред x, затова е префиксен унарен оператор.

Накратко:
ПРЕФИКСЕН = ОПЕРАТОРЪТ Е ПРЕДИ ОПЕРАНДА.


3.2. ИНФИКСЕН ОПЕРАТОР

При инфиксния оператор операторът се намира МЕЖДУ два операнда.

Обща форма:

x ОПЕРАТОР y

Примери:

a + b
a - b
a * b
a / b

При:

a + b

имаме:

a → операнд
+ → оператор
b → операнд

Затова + е инфиксен оператор.

Инфиксният оператор обикновено е бинарен, т.е. работи с два операнда.

Накратко:
ИНФИКСЕН = ОПЕРАТОРЪТ Е МЕЖДУ ДВА ОПЕРАНДА.


3.3. ПОСТФИКСЕН (СУФИКСЕН) ОПЕРАТОР

При постфиксния оператор операторът се намира СЛЕД операнда.

Обща форма:

x ОПЕРАТОР

Примери:

x++
x--

При:

x++

операторът ++ е след x, затова е постфиксен.

Накратко:
ПОСТФИКСЕН = ОПЕРАТОРЪТ Е СЛЕД ОПЕРАНДА.


4. ЛЕСЕН НАЧИН ЗА ЗАПОМНЯНЕ

Префикс:

++x

ОПЕРАТОР → ОПЕРАНД


Инфикс:

x + y

ОПЕРАНД → ОПЕРАТОР → ОПЕРАНД


Постфикс:

x++

ОПЕРАНД → ОПЕРАТОР


5. ПРИМЕР, КОЙТО СЪЧЕТАВА ТРИТЕ ПОНЯТИЯ

int x = 5 + 2 * 3;

Приоритет:
* има по-висок приоритет от +.

Следователно:

5 + (2 * 3)

Резултат:

5 + 6 = 11


Асоциативност:

При:

20 / 5 * 2

/ и * имат еднакъв приоритет и са ляво-асоциативни:

(20 / 5) * 2 = 8


Позиция:

++x → префиксен оператор
a + b → инфиксен оператор
x++ → постфиксен оператор
- Асоциативност

- Позиция на оператора спрямо аргумента - префиксен, инфиксен и суфиксен (постфиксен)
