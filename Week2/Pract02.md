Всеки оператор се характеризира с:

- Приоритет

- Асоциативност

- Позиция на оператора спрямо аргумента - префиксен, инфиксен и суфиксен (постфиксен)


## Примери 


**1.** Какво ще отпечата на екрана следният код?

```c
#include <stdio.h>

int main() {
    
    printf("%d\n", (((false || ((!false && true) || 0)) && false) && 1));
    return 0;
}

```

**2.** Какво ще отпечата на екрана следният код?
```c
#include <stdio.h>

int main() {
    int first = 7;
    int second = 2;

    printf("%d\n", 2 * first / (second * (25 / 10)));
    printf("%f\n", 2 * first / (second * 2.5));
    
    return 0;
}


```

**3.** Какво ще се случи след компилиране на следния код?
```c
#include <stdio.h>

int main() {
    int num = 5;
    
    printf("%d\n", ((num == 5) && (num >= 3) || (num / !num)));
    
    return 0;
}


```

## Задачи




**1.** Въвежа се цяло число. Да се отпечата 1, ако числото е валидна оценка от училище  - [2,6], a 0 - ако не е валидна.

Вход:
```c++
5
```
Изход:

```c++
1
```





**2.** Да се напише програма, която приема 4 цели числа и отпечатва 1, ако числата образуват геометрична прогресия в реда, в който са въведени, a 0 - ако съответно не образуват.

Вход:
```c++
3 9 27 81
```
Изход:

```c++
1
```

**3.** Да се напише програма, която чете от конзолата 2 реални числа и разменя стойностите им без допълнителна промелнива.

**4.** Да се напише програма, която чете от конзолата 2 числа и извежда по-голямото от тях.

Вход:
```c++
3.14
2.71
```
Изход:

```c++
3.14
```

**5.** Напишете програма, която приема цяло число и отпечатва числото, ако е двуцифрено, или последната му цифра, ако не е.

Вход:
```c++
19
```
Изход:
```c++
19
```
Вход:
```c++
1985
```
Изход:
```c++
5
```

**6.** От конзолата се въвеждат 5 цели числа. Да се изведе сумата на нечетните числа.

Вход:
```c++
4 9 19 6 5
```
Изход:
```c++
33
```

## Бонус задачи

```c++

```
