Всеки оператор се характеризира с:

- Приоритет

- Асоциативност

- Позиция на оператора спрямо аргумента - префиксен, инфиксен и суфиксен (постфиксен)


### Най-често използвани форматиращи спецификатори в C

| Спецификатор | Тип данни | Пример |
| :--- | :--- | :--- |
| `%d` | Integer (Цяло число) | `printf("%d", 42);` |
| `%u` | Unsigned int (Цяло число без знак/ положително число) | `printf("%u", 42);` |
| `%f` | Float (Число с плаваща запетая) | `printf("%f", 3.14);` |
| `%lf` | Double (Число с двойна прецизност) | `printf("%lf", 3.14);` |
| `%Lf` | Long double  | `printf("%Lf", 3.14L);` |
| `%s` | String (Текст / Низ) | `printf("%s", "Hello");` |
| `%c` | Character (Символ) | `printf("%c", 'A');` |
| `%p` | Pointer Address (Адрес на указател) | `printf("%p", ptr);` |

## Примери 


**1.** Какво ще отпечата на екрана следният код?

```c
#include <stdio.h>

int main() {
    
    printf("%d\n", (((false || ((!false && true) || 0)) && false) && 1));
    return 0;
}

```

**2.** Какво ще отпечата на екрана следният код?
```c
#include <stdio.h>

int main() {
    int first = 7;
    int second = 2;

    printf("%d\n", 2 * first / (second * (25 / 10)));
    printf("%f\n", 2 * first / (second * 2.5));
    
    return 0;
}


```

**3.** Какво ще се случи след компилиране на следния код?
```c
#include <stdio.h>

int main() {
    int num = 5;
    
    printf("%d\n", ((num == 5) && (num >= 3) || (num / !num)));
    
    return 0;
}


```

**4.** Посочете реда на изпълнение на операторите в следния израз:  
a) `a = 7 + 5 * 3 / 2 - 4`  
б) `a = 12 % 3 + 3 * 3 - 4 / 5`  
в) `a = (4 * 5 * (5 + (6 * 2 / (6))))`
