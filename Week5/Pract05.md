# Побитови операции
Прилагат се върху един бит или набор от повече отделни битове на двоични числа.

 - Побитово И (**&**)    

|        |           |   
|--------|-----------|   
| a      | 1001 0110 |   
| b      | 1010 1100 |
| a&b    | 1000 0100 |


 - Побитово ИЗКЛЮЧВАЩО ИЛИ  (**^**)

|        |           |
|--------|-----------|
| a      | 1001 0110 |
| b      | 1010 1100 |
| a&b    | 0011 1010 |

 - Побитово отместване (**<<**) (**>>**)


|        |           |
|--------|-----------|
| a      | 1001 0110 |
| a << 2 | 0101 1000 |
| a >> 2 | 0010 0101 |

- Побитовa негация (**~**) 


|    |           |
|----|-----------|
| a  | 1001 0110 |
| ~a | 0110 1001 |




## Задачи

**1.** Да се прочете число от конзолата, което с побитови операции да се провери дали е четно.

**Пример:**

```c
8 ---> true
7 ---> false
```

**2.** Да се прочете число от конзолата, което с побитови операции се повдига 2 на степен k.

**Пример:**

```c
8  ---> 256
```

**3.** Да се прочете число от конзолата и да се върне стойността на бит на дадена позиция(брои се от дясно наляво).

**Пример:**
```c
а = 150 // 1001 0110
а, 3 ---> 0
а, 4 ---> 1
```

**4.** Да се въведат от конзолата цяло число a и позиция pos. Да се занули битът на числото a, намиращ се на позиция pos, 
и да се изведе полученият резултат.

**Пример:**

```c
а = 150 // 1001 0110
Вход: 150 2
Изход: 146 // 1001 0010

Вход: 150, 3
Изход: 150 // 1001 0110
```

**5.**Да се въведат от конзолата цяло число a и позиция pos. Да се направи битът на числото a, намиращ се на позиция pos, равен на 1, 
и да се изведе полученият резултат.
**Пример:**

```c
а = 150 // 1001 0110
Вход: 150, 5
Изход: 182 // 1001 0110

Вход: 150, 7
Изход: 150 

```


**6.** Да се въведат от конзолата цяло число a и позиция pos. Да се обърне битът на числото a, намиращ се на позиция pos (ако е 0 да стане 1, а ако е 1 да стане 0), 
и да се изведе полученият резултат.

```c
а = 150 // 1001 0110
a, 3 ---> 158 // 1001 1110
a, 2 ---> 146 // 1001 0010
a, 7 ---> 18  // 0001 0010
```


**7.** Да се въведат от конзолата цяло число a, позиция pos и стойност value (0 или 1). Да се промени битът на числото a на позиция pos със зададената стойност value
 и да се изведе полученият резултат.
**Пример:**

```c
а = 150 // 1001 0110
a, 0, 0 ---> 150 // 1001 0110
a, 6, 1 ---> 214 // 1101 0010
a, 1, 0 ---> 148 // 1001 0100
```

**8.** Да се въведе от конзолата цяло число a. Да се обърне най-десният бит в двоичното представяне на числото, който има стойност 1, 
и да се изведе полученият резултат.
**Пример:**

```c
а = 150 // 1001 0110 
 ---> 148 // 1001 0100
```

**9.** Да се въведе от конзолата цяло число a. Да се обърне най-левият бит в двоичното представяне на числото, който има стойност 0, 
и да се изведе полученият резултат.

**Пример:**

```c
а = 150 // 1001 0110
а ---> 214 // 1101 0110
```

**10.** Да се въведат от конзолата две цели числа a и b. Да се разменят стойностите им, 
без да се използва допълнителна променлива, като се приложат побитови операции. Да се изведат двете числа след размяната.

```c
Вход:
5 9

Изход:
a = 9
b = 5
```
**11.** Да се въведат от конзолата две цели числа a и b. Да се провери дали двоичните им представяния съдържат еднакъв брой битове със стойност 1 
и еднакъв брой битове със стойност 0(дали са пермутация).
Да се изведе съответното съобщение.

**Пример:**

```c
а = 7 // 0111
b = 11 // 1011
c = 8 // 1000
a, b ---> true
a, c ---> false
```

**12.** Да се въведе от конзолата цяло число a. Да се преброят битовете със стойност 1 в двоичното представяне на числото и да се изведе техният брой.

**Пример:**

```c
8 ---> 1
11 ---> 3
```
