# Побитови операции
Езикът C предоставя шест оператора за манипулация на битове; те могат да се прилагат само към цели числени операнди, а именно char, short, int и long, независимо дали са със знак (signed) или без знак (unsigned).
Прилагат се върху един бит или набор от повече отделни битове на двоични числа.

 - Побитово И (**&**)    

|        |           |   
|--------|-----------|   
| a      | 1001 0110 |   
| b      | 1010 1100 |
| a&b    | 1000 0100 |


 - Побитово ВКЛЮЧВАЩО ИЛИ  (**|**)

|        |           |
|--------|-----------|   
| a      | 1001 0110 |   
| b      | 1010 1100 |
| a\|b    | 1011 1110 |  


 - Побитово ИЗКЛЮЧВАЩО ИЛИ  (**^**)

|        |           |
|--------|-----------|
| a      | 1001 0110 |
| b      | 1010 1100 |
| a^b    | 0011 1010 |

 - Побитово отместване (**<<**) (**>>**)


|        |           |
|--------|-----------|
| a      | 1001 0110 |
| a << 2 | 0101 1000 |
| a >> 2 | 0010 0101 |

- Побитовa негация (**~**) 


|    |           |
|----|-----------|
| a  | 1001 0110 |
| ~a | 0110 1001 |  

---  

### Приоритет и асоциативност на побитовите оператори

| Оператор | Операция                     | Приоритет    | Асоциативност  |
|----------|------------------------------|--------------|----------------|
| ~        | Побитово допълнение (NOT)    | 1  | Отдясно наляво |
| <<       | Изместване наляво            |  2   | Отляво надясно |
| >>       | Изместване надясно           | 2   | Отляво надясно |
| &        | Побитово И (AND)             | 3 | Отляво надясно |
| ^        | Изключващо ИЛИ (XOR)         | 4 | Отляво надясно |
| \|       | Включващо ИЛИ (OR)           | 5| Отляво надясно |

### Какво е бит маска ?
Битмаскирането (bitmasking) е техника за използване на отделните битове на дадено число с цел ефективно представяне и манипулиране на множество състояния.
При битмаскирането всяка двоична цифра (0 или 1) може да служи като флаг, който показва дали дадена характеристика, елемент или състояние е активно или неактивно.

### Повдигане на стойност на бит 
За да вдигнем стойността на определен бит, правим бит маска чрез включващо ИЛИ (|).  

### Пример : 
```c
int a = 5;
//a = 00000101

int setBit = 1;
//setBit = 00000001

a |= (setBit << 4);

//Вече а има стойност 11 и изглежда така
// а = 00001101
```


### Смъкване на стойност на бит 
За да смъкнем стойността на определен бит, правим бит маска чрез побитово И (&).  

### Пример:
```c
int a = 6;
//a = 00000110

int unsetBit = 0;
//unsetBit = 00000000

a &= unsetBit << 3;
//Вече а има стойност 2 и изглежда така
// а = 00000020
```  

### Защо се използват побитови оператори?  
Побитовите оператори са се използвали много повече в програмирането, когато компютрите не са разполагали с толкова много памет, колкото днес. Те все още се използват от хората, които работят по вградени (embedded) устройства с ограничения на паметта.
Най-малкото пространство, което една променлива може да заеме, е 1 байт. Причината за това е, че той е най-малката единица адресируемо пространство, до която централният процесор (CPU) може да се отнесе.
Дори една  променлива, която има стойности само 1 за истина и 0 за лъжа заема 4 байта и като се замислим, ние не ползваме 90% от останалите байтове.

Пример: 
```c
Int a = 1;
a = 0000000000000001

Int b = 0;
b = 0000000000000000
```  

Това не е особено практично, ако се опитвате да пестите памет.
Повечето приложения имат множество флагове (признаци), особено тези, които се отнасят до физически хардуер.
За да извлекат максимална полза от наличното пространство, програмистите комбинират множество флагове в един единствен байт, което им позволява да съхраняват до 32 различни булеви стойности.
Точно това ви е необходимо, ако се опитвате да пестите памет на малко устройство.



## Задачи

**1.** Да се прочете число от конзолата, което с побитови операции да се провери дали е четно.

**Пример:**

```c
8 ---> true
7 ---> false
```

**2.** Да се прочете число от конзолата, което с побитови операции се повдига 2 на степен k.

**Пример:**

```c
8  ---> 256
```

**3.** Да се прочете число от конзолата и да се върне стойността на бит на дадена позиция(брои се от дясно наляво).

**Пример:**
```c
а = 150 // 1001 0110
а, 3 ---> 0
а, 4 ---> 1
```

**4.** Да се въведат от конзолата цяло число a и позиция pos. Да се занули битът на числото a, намиращ се на позиция pos, 
и да се изведе полученият резултат.

**Пример:**

```c
а = 150 // 1001 0110
Вход: 150 2
Изход: 146 // 1001 0010

Вход: 150, 3
Изход: 150 // 1001 0110
```

**5.**Да се въведат от конзолата цяло число a и позиция pos. Да се направи битът на числото a, намиращ се на позиция pos, равен на 1, 
и да се изведе полученият резултат.

**Пример:**

```c
а = 150 // 1001 0110
Вход: 150, 5
Изход: 182 // 1001 0110

Вход: 150, 7
Изход: 150 

```


**6.** Да се въведат от конзолата цяло число a и позиция pos. Да се обърне битът на числото a, намиращ се на позиция pos (ако е 0 да стане 1, а ако е 1 да стане 0), 
и да се изведе полученият резултат.

**Пример:**

```c
а = 150 // 1001 0110
a, 3 ---> 158 // 1001 1110
a, 2 ---> 146 // 1001 0010
a, 7 ---> 18  // 0001 0010
```


**7.** Да се въведат от конзолата цяло число a, позиция pos и стойност value (0 или 1). Да се промени битът на числото a на позиция pos със зададената стойност value
 и да се изведе полученият резултат.

**Пример:**

```c
а = 150 // 1001 0110
a, 0, 0 ---> 150 // 1001 0110
a, 6, 1 ---> 214 // 1101 0010
a, 1, 0 ---> 148 // 1001 0100
```

**8.** Да се въведе от конзолата цяло число a. Да се обърне най-десният бит в двоичното представяне на числото, който има стойност 1, 
и да се изведе полученият резултат.

**Пример:**

```c
а = 150 // 1001 0110 
 ---> 148 // 1001 0100
```

**9.** Да се въведе от конзолата цяло число a. Да се обърне най-левият бит в двоичното представяне на числото, който има стойност 0, 
и да се изведе полученият резултат.

**Пример:**

```c
а = 150 // 1001 0110
а ---> 214 // 1101 0110
```

**10.** Да се въведат от конзолата две цели числа a и b. Да се разменят стойностите им, 
без да се използва допълнителна променлива, като се приложат побитови операции. Да се изведат двете числа след размяната.

**Пример:**
```c
Вход:
5 9

Изход:
a = 9
b = 5
```
**11.** Да се въведат от конзолата две цели числа a и b. Да се провери дали двоичните им представяния съдържат еднакъв брой битове със стойност 1 
и еднакъв брой битове със стойност 0(дали са пермутация).
Да се изведе съответното съобщение.

**Пример:**

```c
а = 7 // 0111
b = 11 // 1011
c = 8 // 1000
a, b ---> true
a, c ---> false
```

**12.** Да се въведе от конзолата цяло число a. Да се преброят битовете със стойност 1 в двоичното представяне на числото и да се изведе техният брой.

**Пример:**

```c
8 ---> 1
11 ---> 3
```
